03 / Teaching

Teaching is not about finishing a syllabus.

I want students to leave the classroom able to build, troubleshoot and reason about systems on their own.

CSE / OS 01

Operating Systems

Understanding how software interacts with hardware through processes, memory, scheduling, synchronization and file systems.

Processes Threads Scheduling Memory Synchronization File Systems Linux Embedded OS
CSE / NETWORK 02

Computer Networks

Making networking practical through topology design, addressing, configuration, simulation and troubleshooting.

TCP/IP Subnetting VLAN DHCP Routing Cisco Packet Tracer Troubleshooting

Teaching Philosophy

Don't just explain the system. Let students build it. Break it. Then understand why it broke.
